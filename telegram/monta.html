Monta tu propia Bitácora, gratis

La app que te dice cuánto vale de verdad cada apuesta, lleva tu cuenta real y desenmascara a los tipsters. Tuya, para ti y tus amigos, sin pagarle a nadie.

⏱️ 40–60 min💸 $0📱 Se puede desde el celular (mejor en compu)🧑‍💻 No necesitas programar
Tu avance0 de 7

1Crea tus cuentas

~10 min · todas gratis, sin tarjeta
  1. GitHub — github.com/signup. Ahí vive el código y los procesos automáticos.
  2. Vercel — vercel.com/signup → "Continue with GitHub". Ahí vive tu página.
  3. Supabase — supabase.com → "Continue with GitHub". Es tu base de datos.
  4. The Odds API — the-odds-api.com → plan Starter (gratis). Te llega una clave al correo: guárdala.

2Crea tu bot de Telegram

~3 min
  1. En Telegram busca @BotFather y escríbele /newbot.
  2. Ponle un nombre (ej. "Bitácora de Juan") y un usuario que termine en bot.
  3. Te da un token parecido a 123456789:AAH.... Guárdalo, es secreto.
  4. Abre tu bot nuevo y mándale "hola".
  5. Para saber tu chat id: busca @userinfobot en Telegram y escríbele cualquier cosa; te responde tu número (Id).

3Prepara tus claves (aquí mismo)

~2 min · todo se queda en tu celular, nada se envía

Te genero dos contraseñas largas al azar y armo los textos que vas a pegar en los siguientes pasos.

BOT_CLAVE—
WEBHOOK_SECRET—
Tu página será—
📝 Guarda estas dos claves en tus notas: las vas a pegar en Supabase y en Vercel. Si recargas la página se quedan guardadas en este navegador.

4Arma la base de datos (Supabase)

~8 min
  1. En Supabase: New project. Nombre el que quieras, contraseña larga, región East US (la más cercana a Vercel). Espera ~2 min a que se cree.
  2. Abre el archivo del esquema: supabase/esquema.sql → botón Copy raw file (el ícono de copiar).
  3. En Supabase ve a SQL Editor → New query, pega todo y presiona Run. Debe decir "Success".
  4. Nueva query: pega esto (ya trae tus datos) y Run: 
    Llena el paso 3 primero.
    El token de GitHub del renglón "github" lo sacas en el paso 6 y regresas a pegarlo. Mientras, déjalo así.
  5. Ve a Project Settings → API Keys, pestaña "Legacy API keys", y copia la anon public (empieza con eyJ). La Project URL está en Project Settings → Data API (es tipo https://xxxx.supabase.co).

5Publica tu página (un botón)

~5 min

Este botón copia el proyecto a tu GitHub y lo publica en tu Vercel. Te va a pedir 7 datos:

  2. Conecta tu bot abriendo este link una sola vez:

    Debe decir "ok":true.

6Enciende los procesos automáticos (GitHub)

~8 min

Son los que escanean momios 2 veces al día, califican resultados y calculan el Gurú. Corren solos en GitHub, gratis.

  1. En tu repositorio nuevo (tuusuario/bot-apuestas): Settings → Secrets and variables → Actions.
  2. Pestaña Secrets → New repository secret, crea 3:
    • ODDS_API_KEY → tu clave de The Odds API
    • TELEGRAM_TOKEN → el token de BotFather
    • TELEGRAM_CHAT_ID → tu chat id
  3. Pestaña Variables → New repository variable: BOT_URL → la dirección de tu página
  4. Pestaña Actions: si te pregunta, presiona "I understand my workflows, go ahead and enable them".
  5. Para que Supabase pueda despertar los procesos a su hora, crea un token: GitHub → Fine-grained token → Repository access: solo tu repositorio → Permissions → Actions: Read and write → Generate. Cópialo y en Supabase (SQL Editor) corre: 
    update privado.secretos set valor = 'PEGA-AQUI-TU-TOKEN' where nombre = 'github';

7Pruébalo

~3 min
  1. En Telegram escríbele /start a tu bot.
  2. En GitHub: Actions → Alertas de apuestas → Run workflow. En un minuto te llegan las señales (si hay partidos ese día).
  3. En tu página crea tu usuario: en el bot escribe cuenta tuusuario tucontraseña.
  4. Para invitar amigos: menú → 🛠️ Administrador → crear invitación y compartes el link.
🎉 ¡Listo! Ya tienes tu propia Bitácora. Personalízala: colores, ligas, textos… todo está en el código y es tuyo.

?Si algo falla

  • La página dice "error de base de datos": revisa SUPABASE_URL, SUPABASE_KEY y que BOT_CLAVE sea igual en Vercel y en Supabase.
  • El bot no contesta: abre otra vez el link del paso 5; revisa que TELEGRAM_TOKEN esté bien.
  • No llegan señales: corre "Alertas de apuestas" a mano en Actions y abre el registro; casi siempre es la ODDS_API_KEY o que ese día no hay partidos.
  • Los procesos no corren solos: falta el token de GitHub del paso 6 o el usuario/repositorio en la función privado.disparar (lo pone el SQL del paso 4).
  • ¿Atorado? Abre un Issue en GitHub y la comunidad te ayuda.
